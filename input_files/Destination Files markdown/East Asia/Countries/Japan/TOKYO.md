# 10. BUDGET STRATEGY

Where money can be saved:  
- Use metro 24/48/72hr pass + Suica + JR Tokyo Wide Pass if going Hakone/Fuji
- Stay in Asakusa/Ueno business hotel vs Ginza/Shinjuku luxury - Save 40%
- Eat at ramen + gyudon + konbini + Tsukiji market $8-$15 vs Ginza sushi $100+
- Free attractions - Meiji Shrine, Senso-ji, Yoyogi Park, Imperial Palace East Garden, Shibuya Crossing view free
- Travel Jan-Feb, Jun - Hotels 20-30% cheaper

Where saving money is usually NOT recommended:  
- Very cheap hostel far from Yamanote line - Waste time in metro 1hr
- No reservation for TeamLab/Disneyland - Sold out same day
- Cheap sushi conveyor only - Miss real sushi experience once
- No Suica/Pasmo - Buying ticket each time slow

Travel-agent rule:  
Tokyo budget = $100/day budget (hostel + metro + ramen), $200-$300/day mid (3★ + food + attractions), $600-$1200/day luxury (5★ + fine dining). Metro is best - Taxi expensive $20 for 3km + night surcharge.

# 32. TRAVEL AGENT INSIGHTS

#### What inexperienced planners often do wrong
- Try to cover Shibuya + Harajuku + Shinjuku + Asakusa + Ueno + Ginza + Odaiba in 1 day - Tokyo huge + metro transfer 30min + walking 20k steps. Max 2 clusters/day.
- Book hotel far from Yamanote line to save $30 - Waste 1hr/day in metro + taxi $30 extra. Must stay near Yamanote station.
- Forget to book TeamLab/Disneyland/Sumo/Ghibli Museum in advance - Sold out same day/week. Book 1 month ahead.
- Plan Tsukiji Outer Market afternoon - Best 7-10 AM breakfast. Afternoon many stalls closed.
- Use taxi for all transport - Expensive $20 per 3km + traffic. Metro $5/day with Suica is best + fast.
- Forget last train midnight - Stranded in Shibuya after 12:30 AM taxi surge $50-$100.

#### What an experienced planner does differently
1. Starts with purpose  
   - First-timer = Asakusa + Meiji + Shibuya + Shinjuku + Tsukiji + TeamLab  
   - Family = Disneyland + TeamLab + Ueno Zoo + Odaiba  
   - Luxury = Private sumo + private sushi + private tea + Aman

2. Groups by geography: West Tokyo Shibuya/Harajuku/Shinjuku together, East Tokyo Asakusa/Ueno/Akihabara/Skytree together, Central Ginza/Tokyo Station/Tsukiji together, Bay Odaiba/TeamLab/Roppongi together.

3. Uses hotel location strategically: SHINJUKU/SHIBUYA for nightlife/shopping first-timers, ASAKUSA/UENO for culture/family/budget, GINZA/OTEMACHI for luxury/business/Shinkansen.

4. Places Tsukiji morning 7-10 AM + Shibuya Sky sunset 4-6 PM + TeamLab afternoon/evening. Avoids crowds + best light.

5. Treats Tokyo as 2 areas/day + rest at cafe/depachika - Not checklist 6 areas.

6. Always pre-books TeamLab + Disneyland + sumo tournament + Michelin sushi 1-3 months ahead + arranges Suica + pocket wifi.
