# 1. DESTINATION SUMMARY

short_description:  
Hiroshima & Nagasaki are Japan’s two atomic bomb cities, now symbols of peace - Powerful, emotional, must-visit for history. Hiroshima is famous for Peace Memorial Park + A-Bomb Dome + Museum + Miyajima floating torii + okonomiyaki. Nagasaki famous for Peace Park + Dejima Dutch history + Glover Garden + Gunkanjima battleship island + Chinatown + champon + castella. 400km apart. Usually visited as 2N Hiroshima + Miyajima + optional 2N Nagasaki for deep peace + history + Kyushu route.

travel_agent_summary:  
Hiroshima & Nagasaki work best as 2 nights Hiroshima + Miyajima for first Japan peace + culture + UNESCO, plus optional 2 nights Nagasaki for Kyushu extension with Fukuoka/Beppu.

For first-time visitors, balance Hiroshima Peace Park + A-Bomb Dome + Museum + Miyajima floating torii + Itsukushima Shrine + okonomiyaki.

For history + peace travelers, deep dive - Hiroshima Peace Memorial + Museum audio guide + Miyajima + Nagasaki Peace Park + Atomic Bomb Museum + Dejima + Glover Garden + Gunkanjima cruise.

For families, Hiroshima Peace Park educational + Miyajima deer + torii + ropeway + Aquarium + Nagasaki Penguin Aquarium + Glover Garden.

# 10. BUDGET STRATEGY

Where money can be saved:  
- Use JR Pass / Sanyo Shinkansen Pass + tram day pass $6 + ferry Miyajima JR Pass covers ferry JR
- Stay in Hiroshima city business hotel vs Miyajima ryokan - Save 50% but miss floating torii sunrise/sunset. 1N Miyajima worth splurging.
- Eat at okonomiyaki $8 + oysters $10 + convenience + Nagasaki champon $8 + Chinatown
- Free attractions - Peace Park + A-Bomb Dome + Peace Park Nagasaki + Dejima outside + Glover outside
- Travel Dec-Feb + Jun - Hotels 20-30% cheaper + oysters best winter

Where saving money is usually NOT recommended:  
- Skip Miyajima overnight to save - Best is overnight with floating torii sunset/sunrise empty without day crowds
- No audio guide at Peace Museum - Need context + emotional + history
- Cheap Gunkanjima tour with no landing - Landing depends on whether + need a reputable operator
- No reservation for Miyajima ryokan Iwaso with torii view + Aug 6/9 hotels - Sold out 6 months early

Travel-agent rule:  
Hiroshima 1N $120-$200 mid + 2N $250-$400 with Miyajima ryokan 1N. Nagasaki 2N $200-$350 mid. Shinkansen Osaka→Hiroshima $70 + Hiroshima→Nagasaki via Hakata $80-$120 + tram + ferry cheap. Miyajima ryokan worth a splurge for torii view.

# 11. ARRIVAL INFORMATION

Hiroshima:  
- Primary airport: Hiroshima Airport HIJ - 50km east of city, 50min limousine bus $12 to Hiroshima Station.
- Main station: Hiroshima Station - Shinkansen from Osaka 90min, Tokyo 4hr, Fukuoka 70min. Best way.
- Tram: From Hiroshima Station to Peace Park 20min $2.

Miyajima:  
- From Hiroshima: Hiroshima Station→Miyajimaguchi Station JR 25min + ferry 10min $4 to Miyajima Island. JR Pass covers JR train + JR ferry.

Nagasaki:  
- Primary airport: Nagasaki Airport NGS - 40km north, 45min bus $10 to Nagasaki Station.
- Main station: Nagasaki Station - From Fukuoka Hakata Station, Kamome Shinkansen 90min $25 + bus to airport 45min.
- From Hiroshima to Nagasaki: No direct Shinkansen. Hiroshima→Hakata (Fukuoka) Shinkansen 70min $70 + Hakata→Nagasaki Kamome Shinkansen 90min $25 + bus. Total 3.5hr. Or flight HIJ→NGS 1hr + bus.
