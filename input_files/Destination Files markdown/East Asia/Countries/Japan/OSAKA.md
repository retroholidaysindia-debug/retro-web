# 1. DESTINATION SUMMARY

short_description:  
Osaka is Japan’s kitchen, nightlife, and fun capital - Big, loud, funny, food-obsessed vs Tokyo polished and Kyoto quiet. Famous for Dotonbori neon + Glico running man + takoyaki + okonomiyaki + Osaka Castle + Universal Studios Japan + Umeda Sky Building + Shinsekai. Best 2-3 nights for street food, shopping, nightlife, USJ, and base for Kyoto/Nara/Kobe day trips.

travel_agent_summary:  
Osaka works best as 2-3 night food + fun + base for Kansai circuit with Kyoto 3N + Nara day trip.

For first-time visitors, balance Dotonbori street food + Osaka Castle + Umeda Sky sunset + Shinsekai + Kuromon Market.

For families, Universal Studios Japan 1 full day + Osaka Castle + Aquarium Kaiyukan + Dotonbori + Legoland.

For honeymooners, Osaka is 1-2N fun + food stop - Dotonbori private food tour + Umeda Sky sunset + luxury hotel Conrad/Waldorf + next to Kyoto luxury.

For foodies, #1 street food - Takoyaki, okonomiyaki, kushikatsu Shinsekai, Kuromon Market, Dotonbori.

For nightlife + shopping, Dotonbori + Namba + Shinsaibashi + Umeda + young + affordable vs Tokyo.

For base travellers, Osaka is best hub - Kyoto 30min, Nara 45min, Kobe 30min, Koya-san 90min - All by train.

# 10. BUDGET STRATEGY

Where money can be saved:  
- Stay in Namba/Shinsaibashi business hotel vs Umeda luxury - Save 40% + walk to Dotonbori
- Eat at takoyaki + okonomiyaki + Kushikatsu + Kuromon street food $5-$15 vs Dotonbori fine dining $40
- Use Osaka Amazing Pass $25 - Metro + bus unlimited + 40 attractions free - Castle + Umeda Sky + cruise included
- Use metro day pass $6 + walk Dotonbori-Shinsaibashi-Namba flat
- Travel Jan-Feb, Jun - Hotels 20-30% cheaper + USJ less queue

Where saving money is usually NOT recommended:  
- Cheap hostel far from Midosuji line - Waste time + taxi cost
- No USJ Express Pass peak - 2-3hr queue per ride without Express. Buy Express $80 extra peak essential.
- Skip Dotonbori night - Must night neon + Glico photo + food
- No Osaka Amazing Pass if doing Castle + Umeda Sky + cruise + metro same day - Pass saves money

Travel-agent rule:  
Osaka budget = $70/day budget (hostel + street food + metro), $150-$250/day mid (3★ + food + USJ + pass), $400-$700/day luxury (5★ + fine dining + USJ VIP + private car). Osaka Amazing Pass best value for city day.

# 32. TRAVEL AGENT INSIGHTS

#### What inexperienced planners often do wrong
- Try to do Osaka Castle + Dotonbori + Shinsaibashi + Umeda Sky + Shinsekai + Kaiyukan + USJ in 1 day - Impossible + USJ alone full day. Max 2 clusters + USJ separate day.
- Book hotel far from Midosuji line to save - Waste time + taxi cost. Must Namba/Shinsaibashi/Umeda.
- No USJ Express Pass in peak - 2-3hr queue per ride without Express. Must buy Express 4/7 $80 extra peak essential.
- Do Dotonbori afternoon only - Must night 6-10 PM neon + Glico lights + street food + river cruise night best.
- Forget Osaka Amazing Pass for Castle + Umeda Sky + cruise + metro same day - Pass $25 saves money + free entry.
- Plan USJ + Kyoto same day - USJ 9 AM-8 PM + Kyoto 30min away + tiring + USJ needs full energy.

#### What an experienced planner does differently
1. Starts with purpose  
   - Food + nightlife = Namba/Dotonbori/Shinsaibashi + Kuromon + Shinsekai kushikatsu  
   - Family = USJ 1 full day + Kaiyukan + Castle + Dotonbori food  
   - Base = Osaka as hub for Kyoto/Nara/Kobe day trips + Osaka Amazing Pass for city day

2. Groups by geography: South Namba/Dotonbori/Shinsaibashi/Kuromon together flat walking, North Umeda/Kita/Sky Building together, East Castle/Tennoji/Shinsekai together, Bay USJ/Kaiyukan together.

3. Uses hotel location strategically: NAMBA/SHINSAIBASHI for food/shopping/nightlife + budget-mid + walk to Dotonbori. UMEDA for luxury + business + sky view + department shopping + quieter.

4. Places Dotonbori evening 5-10 PM night neon + Glico + street food + river cruise night + Umeda Sky sunset 5-7 PM + Castle morning 9-11 AM to avoid heat.

5. Treats Osaka as 2 areas/day + USJ separate full day - Not checklist 5 areas same day.

6. Always includes Osaka Amazing Pass for city day + USJ Express Pass peak + private food tour + Kuromon morning + Kobe/Nara day trip as base advantage.
