# 1. DESTINATION SUMMARY

short_description:  
Nara & Nagoya are two contrasting Central Japan hubs - Nara is Japan’s first capital 710 AD, ancient + spiritual with 1200 free-roaming deer + Todai-ji Big Buddha + Kasuga Shrine lanterns + UNESCO temples. Nagoya is Japan’s 4th biggest industrial megacity, Toyota city, modern + castle + Legoland + SCMaglev + miso food. Usually Nara as half-day/day trip from Kyoto/Osaka, Nagoya as 1-2N stop between Tokyo and Kyoto + Legoland + Toyota + castle + gateway to Takayama/Shirakawa-go/Alps.

travel_agent_summary:  
Nara & Nagoya work best as Nara half-day/day trip from Kyoto 45min or Osaka 45min, Nagoya 1-2N industrial + family + base for Chubu.

For first-time visitors, Nara = Nara Park 1200 deer + Todai-ji Temple Big Buddha + Kasuga Taisha lanterns + mochi pounding. Nagoya = Nagoya Castle + Atsuta Shrine + Toyota Museum + SCMaglev + Sakae + Osu shopping.

For families, Nara deer feeding + Todai-ji big + mochi + Nagoya Legoland Japan + SCMaglev + Toyota + Aquarium + Science Museum.

For history lovers, Nara is #1 ancient capital before Kyoto - 1300yr temples UNESCO + first capital history.

For industrial + car lovers, Nagoya Toyota city - Toyota Commemorative Museum + Toyota City factory tour + SCMaglev railway + manufacturing heart.

For foodies, Nara = kakinoha sushi + mochi + sake, Nagoya = Nagoya meshi - hitsumabushi eel, miso katsu, tebasaki chicken wings, kishimen noodles.

For base travelers, Nagoya is best base for Takayama + Shirakawa-go + Ise + Ghibli Park + Legoland.
