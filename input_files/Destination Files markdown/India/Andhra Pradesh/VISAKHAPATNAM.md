# 10. BUDGET STRATEGY

Where money can be saved:  
- Stay in RK Beach area 3★ vs Rushikonda 5★ - Save 40% + near Kailasagiri + Submarine + walkable
- Eat at Andhra meals + bamboo chicken + seafood + local cafes $3-$6 vs 5★ $20
- Use auto + cab day package $20-$30 vs private car $40 for city + beach road
- Araku by APTDC bus + Vistadome train $15 vs private car $60 - Bus+train experience better
- Travel Mar-Sep off-peak - Hotels 30% cheaper

Where saving money is usually NOT recommended:  
- Very cheap hotel near railway station far from beach - Noisy + no sea view + auto cost extra
- No Vistadome train for Araku - Normal train ok but Vistadome glass top + valley view worth $10 extra
- Skip Borra Caves guide to save $5 - Caves dark + need guide + history
- Rushikonda swimming without a lifeguard + monsoon rough sea - Safety first

Travel-agent rule:  
Vizag budget = $30/day budget (hostel + auto + meals), $70-$120/day mid (3★ + cab + Araku Vistadome + food), $150-$250/day luxury (5★ sea view + private car + Araku coffee resort). Auto + cab day package best. Araku Vistadome book 1 week ahead.
